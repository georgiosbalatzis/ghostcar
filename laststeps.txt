Issues fixed during the refactor so far:

- Fixed async load finalization in src/F1PhantomCars.jsx. An aborted or stale telemetry/preset request could clear loading state or disable cancellation for a newer active request. finishCancelableLoad now only finalizes the matching controller, and catch blocks only mutate loading/error state for the active non-aborted controller.

- Fixed tour dismissal persistence in src/F1PhantomCars.jsx. Esc now uses the same dismissal path as the TourOverlay button, so the first-run tour does not reappear after keyboard dismissal.
- Fixed light-theme contrast in src/components/TelemetryPanel.jsx and the empty-state title in src/F1PhantomCars.jsx by using theme text color instead of hardcoded white.
- Fixed same-year gallery/share URL restore after selector collections are cleared. useComparisonSelectors now treats restoreTick as a meetings reload key, so restoring a saved comparison for the currently selected year can still refetch meetings and continue the restore chain.
- Fixed stale stint state during manual driver changes. selectDriverSlot now clears the changed slot's stint list at the same time it clears the selected lap and lap list.
